# Logo source

`rolimons-logo.svg` is the unmodified Rolimon's favicon downloaded from https://www.rolimons.com/favicon.svg, linked by the official website, on November 1, 2026. It identifies Rolimon's values beside trade item prices and totals. The logo belongs to Rolimon's; this independent extension is not affiliated with or endorsed by Rolimon's.

The displayed logo now uses the exact inline SVG path and viewBox from the official site navigation in `src/content.js`. This avoids an external image request or CSS URL resolution. The downloaded favicon is retained as a reference asset.
