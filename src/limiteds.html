Limiteds browser

Browse valued limiteds in a value range, ranked by the value model’s odds of a Rolimon’s value raise. Model odds need each item’s Rolimon’s page, so they load at a polite pace when you click Scan model odds.

Accepts 25000, 25k or 1.5m. Blank = no limit.
Scanned odds are saved for 6 h (even if you close Chrome), so already-scanned items are free. Unscanned items are fetched most promising first (Raising trend, RAP above value, demand). Scan all does every unscanned item in the current filter; keep this tab open while it runs.

Loading Rolimon’s values…

Odds come from the extension’s value model trained on past Rolimon’s value changes; “usual” is how often any item got a raise in that window. Value changes are rare and can follow events the data doesn’t show, so treat odds as a signal, not a promise.
